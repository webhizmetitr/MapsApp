MapsApp 2.0 — Windows x64

1. MapsApp.exe dosyasını açın; Python kurulumu gerekmez.
2. Google Places API (New) anahtarınızı girin.
3. Açılır menüden il seçin. İlçe listesi otomatik güncellenir.
4. Tek ilçe seçin veya ilin tamamını taramak için Tüm ilçeler seçin.
5. Sektör girin. Ekrandaki en fazla API isteği sayısını kontrol ederek taramayı başlatın.
6. Sonuçlar geldikçe listelenir; CSV olarak kaydedilebilir.

81 il ve 973 ilçe çevrimdışı olarak dahildir. Google'ın sunduğu sayfalar her ilçede
otomatik taranır; tekrarlanan işletmeler tekilleştirilir. Durdurma veya API/kota
hatasında alınan sonuçlar korunur.

Google her ilçe/sektör sorgusunda en fazla 60 sonuç sunar. Tüm ilçeleri ayrı
taramak kapsamı artırır ama tüm işletmelerin eksiksiz listesini garanti etmez.
Google kaydında web sitesi bilgisinin olmaması, internette hiç sitesi olmadığı
anlamına gelmez. API faturalandırması açık olmalıdır ve istekler ücretli olabilir.
İstanbul'da Tüm ilçeler seçimi en fazla 117 API isteği oluşturur.

18 birim testi, örnek verili il/ilçe-arayüz-CSV-harita kontrolleri ve gerçek
paketlenmiş EXE'nin açılıp normal kapanması Wine altında doğrulandı. Gerçek
API anahtarıyla arama test edilmedi. EXE dijital imzalı değildir.
Google Maps Platform koşulları veri kullanımı ve saklama için geçerlidir.
