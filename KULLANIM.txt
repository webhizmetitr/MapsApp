MapsApp — Windows x64

1. MapsApp.exe dosyasını çift tıklayarak açın. Python kurulumu gerekmez.
2. Google Places API (New) etkin ve faturalandırması açık projenizin API anahtarını girin.
3. Ülke, şehir/ilçe ve sektör girip İşletmeleri ara düğmesine basın.
4. Sonuçları haritada açabilir veya CSV olarak kaydedebilirsiniz.

API kullanımı ücretli olabilir. Anahtar uygulamaya gömülü değildir ve diske kaydedilmez.
Web sitesi bilgisi Google kaydına dayanır; sitenin kesinlikle olmadığı anlamına gelmez.
Google Maps Platform koşulları veri kullanımı ve saklama için geçerlidir.

Doğrulama: Wine altında 11 test, örnek verili arayüz/CSV/harita kontrolleri ve
paketlenmiş EXE'nin açılıp normal kapanması başarılı. Gerçek Windows bilgisayarda
ve gerçek API anahtarıyla arama henüz test edilmedi. EXE dijital imzalı değildir.
